Projeto da faculdade que busca o signo do usuário pela data inserida e retorna o signo e um personagem com carcterísticas.

recursos usados:

linguagem php
bootsrap
xampp

considerações:

exercício excelente para testar dados inválidos a partir da data como: anos bissextos, dias dos meses 28, 29, 30 e 31, 
signos que ultrapassam o periodo anual.
